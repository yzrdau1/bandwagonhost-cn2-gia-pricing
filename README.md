中国电信回程线路，从便宜到贵大致是这么个顺序：AS4134（ChinaNet/163 网）→ CN2 GT（AS4809 Global Transit）→ CN2 GIA（AS4809 Global Internet Access）→ CTGNet（AS23764，2021 年后新增，性能和价格基本对标 CN2 GIA）。
